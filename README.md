# 📈 محفظتي — إدارة وتحليل الأسهم

تطبيق ويب لإدارة محفظة الأسهم: تسجيل الصفقات، حساب الأرباح/الخسائر، توزيع المحفظة،
تحليل فنّي، تحليل بالذكاء الاصطناعي، وتنبيهات سعرية.

## المميزات

- **متعدد الأسواق**: السعودي (`2222.SR`)، الأمريكي (`AAPL`)، الخليجي، والعملات الرقمية (`BTC-USD`) — عبر Yahoo Finance.
- **أسعار حيّة** تتحدّث تلقائياً كل دقيقة، مع تحويل تلقائي للعملة الأساسية (SAR/USD/AED).
- **أرباح/خسائر** محققة وغير محققة بطريقة متوسط التكلفة.
- **توزيع المحفظة** برسم بياني دائري.
- **تحليل فنّي**: RSI، MACD، متوسطات 50/200، اكتشاف الاتجاه، ومؤشر تجميعي.
- **تحليل AI** (اختياري): رأي مُعلَّل من Claude اعتماداً على المؤشرات.
- **تنبيهات سعرية** عند بلوغ أهداف.
- **خصوصية كاملة**: بياناتك محفوظة في متصفحك (localStorage) — لا خادم ولا قاعدة بيانات.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## تفعيل تحليل الذكاء الاصطناعي (اختياري)

```bash
cp .env.local.example .env.local
# ضع مفتاح ANTHROPIC_API_KEY داخل .env.local
```

التطبيق يعمل كاملاً بدون هذا المفتاح؛ التحليل الفنّي لا يحتاجه.

## النشر على Vercel

```bash
npx vercel
```

أضف متغيّر البيئة `ANTHROPIC_API_KEY` في إعدادات المشروع على Vercel (اختياري).

## رموز الأسهم (Yahoo Finance)

| السوق | مثال |
|---|---|
| السعودي (تداول) | `2222.SR` (أرامكو)، `1120.SR` (الراجحي) |
| الأمريكي | `AAPL`، `NVDA`، `TSLA` |
| الإمارات (دبي) | `EMAAR.DU` |
| العملات الرقمية | `BTC-USD`، `ETH-USD` |

## ملاحظات

- الأسعار عبر Yahoo Finance غير الرسمية، وقد تتأخر ~15 دقيقة (خاصة الأسواق الخليجية).
- كل التحليلات لأغراض معلوماتية فقط وليست نصيحة مالية.
